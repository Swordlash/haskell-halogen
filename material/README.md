# haskell-halogen-material

Implementation of Google Material Components using the
[haskell-halogen-core](../core) library.

This package lives in the [haskell-halogen](https://github.com/Swordlash/haskell-halogen)
monorepo; see the [root README](../README.md) for build instructions. The runnable
example app is in [examples/material](../examples/material).
