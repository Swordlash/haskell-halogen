Work that does not freeze the page

Counting the primes below two million takes a second or two. Counted here, on the page, it takes that time from the page: the spinner below, which the component turns a frame at a time, stops until the count is done. Counted in a Web Worker (another copy of this program, which Halogen.Worker starts from the same app.wasm), it leaves the page free, and the spinner goes on turning.
